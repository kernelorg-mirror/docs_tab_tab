Kernel workflows
----------------
Konstantin Ryabitsev walked us through a project plan for developer workflows. This includes a series of improvements to lore.kernel.org, patchwork, git and other tools with the objectives of:

- Improving security through patch attestation
- Making it easier to collaborate on mailing lists
- Improving the tools maintainers use to track and integrate pending patches
- We discussed the work he has in mind and talked about the best ways to try and support his plans.
